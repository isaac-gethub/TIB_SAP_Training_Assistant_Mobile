TIB SAP Training Assistant Mobile v1.0.8

MOBILE ROLE
- Pre-SAP narrated walkthrough.
- READ / SHOW ME / DO IN SAP / EVIDENCE-DOCUMENTATION / CONFIRM / NEXT.
- Mobile is a companion display only.
- NO SAP GUI Scripting.
- NO SAP screen/session awareness.
- NO automatic SAP-state validation.
- Course content remains in courses.json for Vercel deployment.

SAP-aware recognition belongs exclusively to the Windows/Desktop edition because it must communicate
with SAP GUI running on the same Windows computer.
