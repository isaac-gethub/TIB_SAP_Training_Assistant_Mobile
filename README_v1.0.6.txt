TIB SAP Training Assistant Mobile v1.0.6
LEARNING MODEL CORRECTION

Narration is now a PRE-SAP whole-lab walkthrough:
HEAR HOW THIS LAB IS DONE -> START LAB -> READ -> SHOW ME -> DO IN SAP -> CONFIRM -> NEXT

The narration is NOT used as SAP navigation guidance.
Only authored narration fields are spoken; execution text is not substituted when narration is missing.
SHOW ME remains the SAP navigation/visual guidance function.
v1.0.5 cross-platform install behavior and v1.0.4 PWA assets are preserved.
